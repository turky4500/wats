# MultiWA عربي - منصة واتساب للأعمال

منصة متكاملة لإدارة واتساب للأعمال مع نظام اشتراكات ولوحة إدارة متقدمة.

## 🚀 المميزات

- 🔐 **نظام مصادقة متكامل** - تسجيل دخول/تسجيل مع أدوار مختلفة
- 👤 **لوحة المستخدم** - إدارة الأجهزة والرسائل والاشتراك
- 🛡️ **لوحة الإدارة** - تحكم كامل بالمستخدمين والاشتراكات والأجهزة
- 💳 **نظام اشتراكات** - باقات متعددة (مجاني/فضي/ذهبي)
- 📱 **دعم أجهزة واتساب متعددة** - عبر Baileys
- 📊 **تحليلات وإحصائيات** - رسوم بيانية وتقارير
- 🌐 **واجهة عربية بالكامل** - RTL مع خط Tajawal

## 📋 المتطلبات

- Node.js 20+
- PostgreSQL 15+
- Redis (اختياري للـ Queue)

## 🛠️ التثبيت

```bash
# تثبيت المكتبات
pnpm install

# إعداد قاعدة البيانات
cp .env.example .env
# تعديل ملف .env
pnpm db:generate
pnpm db:push

# تشغيل التطوير
pnpm dev
```
